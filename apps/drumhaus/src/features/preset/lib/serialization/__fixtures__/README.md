# Share-URL fixtures

The share codec is latest-only: it reads and writes exactly the single current `COMPACT_CODEC_VERSION` (v3) and refuses every other `v` (older v1.5 links and versionless pre-#269 links) with `UnsupportedVersionError` (#373).
No _legacy_ share payload is decoded anymore, so there are no frozen legacy `?p=` fixtures.
There are, however, frozen fixtures for the _current_ v3 codec (`share-v3-*.txt`): real emitted bytes pinned on disk so a codec edit is caught against links already in the wild, not only against the in-memory round trip in `url-codec.test.ts` (an encode+decode change made in lockstep would pass a round trip yet break every existing link).

## `share-v3-init.txt` and `share-v3-dense.txt`

Frozen `?p=` payload strings for the compact codec v3, generated by passing the presets below through today's `shareableDocumentToUrl` (compact codec v3, gzip, base64url).
Do not regenerate casually: their whole value is that the bytes are what a v3 build actually emitted. To regenerate deliberately after an intended codec change, encode the two documents below with `shareableDocumentToUrl` and overwrite the files, then update the pinned literals in `frozen-payloads.test.ts`.

- `share-v3-init.txt` - the init document (`v1-current.json` decoded through the document ladder, i.e. the bundled `init.dh`).
  Decodes to: kit `kit-0`, bpm 100, swing 0, default channels (neutral filter `{ highpass, 0 Hz }`, 0 dB volume, centered pan/tune, decay 5 s), master compRatio 5, a single-step chain (A1) with chain disabled.
- `share-v3-dense.txt` - the document migrated from `buildDenseSharePreset()` (see below).
  Decodes to: kit `kit-3`, bpm 137, swing fraction 0.24 (v1.5 knob 64 through the legacy interpretation), channel-0 `volumeDb` null and master `masterVolumeDb` null (the silence spelling), master compRatio 6, and the 3-step chain (A2 B1 D3) with chain enabled. Filter positions land on the low-pass side (channel 0 ~899.6 Hz, channel 3 ~12651 Hz, master ~6003.7 Hz). All lossy fields are pinned to the codec's emitted grid values in `frozen-payloads.test.ts`.

## `dense-preset.ts`

`buildDenseSharePreset()` builds a deterministic dense `PresetFileV1` (0-100 knob space) with every channel param, every master param, bpm 137, swing knob 64, a 3-step chain (A2 B1 D3) with chain enabled, kit-3, and per-step velocities/nudges/ratchets/flams/accents.
It is a synthetic legacy document, not a frozen fixture: `url-codec.test.ts` migrates it to a canonical document to seed dense round-trip and KIT_ORDER-independence cases, and `library/adoption.test.ts` uses it to exercise the document migration ladder.
