# Contributing

Drumhaus is a personal project, and it's essentially finished. I keep development in my own hands, so I generally don't take pull requests - if I decline one, it isn't a judgment on the work.

Bug reports are welcome. Open an issue with steps to reproduce, what you expected, and your browser. Feature requests are fine too, but the instrument is intentionally bounded, so most won't land.

The code is source-available under CC BY-NC-SA 4.0. Fork it, read it, learn from it, build your own thing - that's what it's here for. See [LICENSE](./LICENSE) for terms.
